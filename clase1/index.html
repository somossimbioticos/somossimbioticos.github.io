Parte 5 · APIs

¿Qué es una API?

Una API es la puerta para que tu programa (una web, un bot de WhatsApp, un Excel) le pida cosas a otro servicio, por ejemplo a una IA.

🙋
Tú (tu app)haces el pedido
↓ con tu llave (API key)
🤵
La API = el meserolleva el pedido y trae la respuesta
↓
🔥
La cocina = el modelo de IAGemini, Llama, GPT…
  • 🔑 API key: tu contraseña para usarla. Es secreta.
  • 💲 Pagas por tokens (o es gratis con límites).
  • 🔌 Con una API metes IA en tu web, tu bot o tu negocio.
La idea, en código
pregunta = "Resume este texto en 3 viñetas"
respuesta = ia.chat(modelo="llama-3.3-70b",
                    mensaje=pregunta)
print(respuesta)

APIs de IA gratis: Groq Para programadores

Groq te da una API de IA gratis (con límites) y ultrarrápida: cientos de palabras por segundo con modelos abiertos como Llama, Qwen y GPT-OSS.

  1. 1
    Crea tu cuenta

    Sin tarjeta de crédito.

    🔗 console.groq.com
  2. 2
    Crea tu API key

    Menú API Keys → Create API Key. Guárdala en un lugar seguro.

    🔗 console.groq.com/keys
  3. 3
    Úsala

    Funciona igual que la de OpenAI: cambia solo la dirección y el modelo.

🔗 groq.com
Ejemplo en Python · Groq
# Primero instala la librería:  pip install openai
from openai import OpenAI

cliente = OpenAI(api_key="TU_LLAVE",
    base_url="https://api.groq.com/openai/v1")

r = cliente.chat.completions.create(
    model="llama-3.3-70b-versatile",
    messages=[{"role": "user",
               "content": "Hola, ¿qué es Groq?"}])
print(r.choices[0].message.content)

Cambia TU_LLAVE por tu llave y no la publiques. En Colab, guárdala en 🔑 Secretos.

🎁

Otras APIs con plan gratis

Google AI Studio (Gemini) y OpenRouter (modelos «:free»). Límites típicos: ~30 pedidos por minuto.

🔗 aistudio.google.com/apikey🔗 openrouter.ai
Parte 5 · Gratis · privado · sin internet

IA en tu PC con Ollama

Instálalo desde ollama.com/download, abre la terminal (en Windows: «Símbolo del sistema» o PowerShell) y escribe un comando. La primera vez descarga el modelo.

⚡

Texto rápido y liviano

ollama run gemma3:1b

806 MB · responde en ~1 s en un PC sin tarjeta gráfica (~23 palabras/s). Ideal para resumir, redactar y practicar.

👁️

Analizar una imagen

ollama run moondream "Describe esta foto" ./foto.jpg

1,7 GB · ~30 s por foto sin GPU (responde en inglés). Mejor en español: qwen3-vl:2b (necesita GPU para ir rápido).

🎨

Crear imágenes

ollama run x/flux2-klein "un colibrí en acuarela"

Experimental y por ahora solo en Mac. En Windows o Linux usa la parte 3 del cuaderno de Colab (GPU gratis).

🔗 Cuaderno: imágenes en Colab
🔒

¿Por qué local?

Gratis, privado (tus datos no salen del PC) y funciona sin internet. Más grande el modelo = más inteligente pero más lento.

🔗 ollama.com/download🔗 ollama.com/search
Parte 6 · Los ejemplos

Prompts que funcionan

Un prompt es la instrucción que le das a la IA. Mientras más claro, mejor la respuesta.

La fórmula R · C · T · F · E

Las cinco partes de un buen prompt, con el ejemplo de la clase: un profesor que prepara una clase de genética.

RRolActúa como profesor de biología con 20 años de experiencia
CContextoMis estudiantes son de grado 9 y les cuesta la genética
TTareaCrea una clase de 45 minutos sobre las leyes de Mendel
FFormatoEn tabla: momento, actividad, minutos y materiales
EEjemplos y límitesSin términos en inglés; incluye un juego de 10 minutos
❌

«Hazme una clase de genética»
→ respuesta genérica

✅

R + C + T + F + E
→ lista para usar

✅ El prompt completo
Actúa como profesor de biología con 20 años de experiencia. Mis estudiantes son de grado 9 y les cuesta la genética. Crea una clase de 45 minutos sobre las leyes de Mendel. Entrégala en una tabla con estas columnas: momento, actividad, minutos y materiales. No uses términos en inglés e incluye un juego de 10 minutos.

7 trucos que cambian todo

Frases cortas que mejoran cualquier respuesta. Las que tienen 📋 se pueden copiar.

🙋

Que te entreviste

Antes de responder, hazme las preguntas que necesites.
🧩

Dale ejemplos

«Escribe con este estilo: …» y pega un texto que te guste.

🔁

Itera, no empieces de cero

«Más corto» · «más formal» · «cambia el punto 3»

🧐

Que se autocritique

Revisa tu respuesta como un experto exigente y mejórala.
📦

Separa el texto

Pon lo que pegas entre """ comillas """ o ###.

🎯

Di para quién es

«Para un niño de 10 años» · «para un gerente con 2 minutos»

📋

Pide el formato final

Tabla, viñetas, correo listo para copiar…

Parte 6 · Tokens

Cómo ahorrar tokens (y dinero)

≈ 1,4

tokens por palabra en español

Un token es un pedacito de palabra: las IAs cobran y ponen límites por tokens.

💡 En cada mensaje la IA vuelve a «leer» toda la conversación.

  • 🗂️
    Un chat por tema. Los chats eternos gastan más en cada mensaje.
  • 📝
    Resume y reinicia: pide un resumen y pégalo en un chat nuevo.
    Resume esta conversación en 10 viñetas.
  • ✂️
    Pega solo lo necesario: la página 4, no el PDF de 80.
  • 📏
    Pide respuestas cortas:
    Máximo 5 viñetas, sin introducción.
  • 🧠
    Modelo adecuado: el rápido para lo fácil, el potente solo para lo difícil.
  • 🕸️
    Proyectos grandes: Graphify o búsqueda en tus documentos en vez de pegarlo todo.
